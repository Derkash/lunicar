Réglages et import

Calcul du prix maximum d'achat

Mode marchand (LUNICAR revend aux professionnels) : cote marchand calée sur vendezvotrevoiture.fr (annonces de particuliers × âge × kilométrage × état), offre = cote + prime, plafonnée pour garder la marge minimale sur la revente aux pros. Mode particulier : prix de vente estimé − remise en état − frais fixes − déplacement − marge.

Fourchette client : le bas = prix max d'achat (engagement si les infos sont exactes). Haut : sous le 1er seuil → montant 1 ; sous le 2e seuil → montant 2 ; au-delà → prix max + %, au moins + le minimum (jamais sous le montant 2).

Mode particulier

Déplacement pour aller chercher la voiture (déduit du prix max) : train à l'aller, retour au volant avec carburant et péages. Distance routière calculée depuis le code postal de départ.

Les nouvelles valeurs s'appliquent uniquement aux prochaines estimations.
Les estimations déjà faites gardent les règles en vigueur à leur date ; relancez une estimation pour lui appliquer les nouvelles.
